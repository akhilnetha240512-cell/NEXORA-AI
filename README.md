NEXORA AI

NEXORA AI is a personal Android AI assistant designed for voice and text interaction.

Planned Features

- Voice input and spoken responses
- Telugu, English, and mixed-language support
- Gemini-powered AI assistance
- Customizable assistant responder name for each device
- App launching and supported Android actions
- Confirmation before important actions
- Free cloud APK builds through GitHub Actions

Development

Built for Android with a focus on privacy, user control, and accessibility.

Project status: Initial development.
